# 🎮 Tic-Tac-Toe with Unbeatable AI

An interactive Tic-Tac-Toe game where you play against an AI that uses the Minimax algorithm.

## Features
✅ Play against unbeatable AI
✅ Real-time move detection
✅ Win/Draw conditions
✅ Reset & New Game buttons
✅ Responsive design

## Tech Stack
- HTML — Structure
- CSS — Styling
- JavaScript — Game logic & AI

## Algorithm
The AI uses the **Minimax Algorithm** — a recursive game theory algorithm that:
1. Evaluates all possible moves
2. Scores each outcome
3. Picks the best move

## How to Play
- You are **O**, AI is **X**
- Click any empty box to make your move
- AI responds instantly
- First to get 3 in a row wins!

## Game Theory
This project demonstrates:
- Minimax algorithm
- Game tree evaluation
- Recursive decision making
